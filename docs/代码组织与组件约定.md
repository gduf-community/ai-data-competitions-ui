# Web 代码组织与组件约定

源码核对：2026-10-15，Web `0b0d594952897ea1d90c39b7afb5b7430571f078`。当前 Next.js 16.3.8 App Router、React 19.2.3、TypeScript 5.9.3、Tailwind 4.1.18；完整依赖见 [package.json](../package.json)。沿现有 Radix、React Hook Form/Zod、TanStack Table、Recharts/ECharts 和 Framer Motion，不建立第二套框架。

## 找到正确的层

| 位置 | 职责与依赖 |
| --- | --- |
| [src/app](../src/app) | Server Component 页面、布局、加载/错误页及唯一 BFF；路由组不进入 URL |
| [src/proxy.ts](../src/proxy.ts) | 模式阻断、旧登录入口、API 访问检查、内部 callback 路径与业务 CSRF Cookie |
| [web-transport](../src/lib/web-transport.ts) / [BFF](<../src/app/api/[...path]/route.ts>) | 固定 origin、按路径/方法透传、Cookie/来源/IP/服务身份；不处理业务事务 |

## 页面与数据

Server Component 先取对应公开/私有 DTO，再把必需字段传给 Client Component；公开 JSON 读取和浏览器 BFF 策略分别维护。`readOptionalAPI` 仅把 404 转 null，其他异常继续交给页面/错误边界；无 Mock fallback。`cache()` 用于既有请求内复用，不据此宣称跨请求持久缓存。

`getWebSession` 在 public 为 null，trusted 只把 API 401 视为匿名。后台壳与社团页面使用 API capability/allowedActions，不能从菜单、一个 role 或前端本地函数授予权限。组件可以辅助显隐，写入仍由 API 当前身份、对象和状态校验。

## 表单、列表与异步行为

个人奖状（API #170，配套API #159/Web #158）：上传与管理共用 `profiles.ts` 字段长度常量，奖级使用原文输入及预设建议，不将金银铜折算为一二三等奖；自定义展示文案不代替结构化奖级。后台多维筛选只针对当前审核列表，状态切换清除依赖列表的比赛/年份筛选，失效已选标签仍可移除；多选触发器支持Enter/Space/下方向键。保存以API `changed`结果更新重审提示，重复保存不伪造pending状态。公共限长输入组件由API #160继续跟踪。

- 优先改现有组件/函数；通用 UI 不内嵌后端授权或状态机。比赛默认值/转换集中于 [competition-form-model](../src/components/admin/competition-form-model.ts)，父级 [use-competition-management](../src/components/admin/use-competition-management.ts) 负责读取、提交及刷新。
- [useJSONResource](../src/hooks/use-json-resource.ts) 适用于完整集合读取：URL/revision 变化取消旧请求，失败保留同 URL 旧数据并给出 error/reload。写命令仍由领域页显式执行；不要为所有命令预设自动重试。
- [AdminDataTable](../src/components/admin/admin-data-table.tsx) 的完整数组可本地过滤；manual/external 分页禁止对当前页伪装全量搜索/排序。公共分页和安全样本搜索的范围见[搜索协议](./搜索协议.md)。
- 提交中限制重复操作，失败保留输入并展示字段/根错误，成功按现有资源 reload 或 router.refresh 同步。是否有确认交互以对应组件为准，不声称所有既有入口已统一。
- 部分组件仍直接 fetch/fetchWithCsrf；维护时沿既有合同核对 response.ok/包裹/CSRF/取消，不能因引入共享客户端而认为旧入口都自动具备这些行为。

## 图片与编辑器

[LazyFillImage](../src/components/shared/lazy-fill-image.tsx) 保留尺寸、失败占位和 URL 变化重试；上传素材绕过 Next 图片缓存，按 API 当前可见性/版本读取，外部静态图沿 next.config。图片 URL、对象归属和上传成功是不同条件，不能用占位图通过封面校验。

[RichTextEditor](../src/components/forms/rich-text-editor.tsx) 保留浏览器 DOM/选区，本地 value 回声与组合输入不重写 DOM，切文通过 editorKey 重建；[ClubContentEditor](../src/components/clubs-admin/club-content-editor.tsx) 维护保存 ID/revision、上传阻塞和发布失败重试。富文本在 API/展示边界清洗，Markdown 不开启原始 HTML。

## 边界与验证

Web 不导入 API 仓库、数据库/存储管理 SDK、Auth.js 服务端签名或后端事务模块。服务凭据只能停留在 server-only/传输侧；客户端不能选择 API origin 或携带服务 Bearer。边界脚本和产物检查会拒绝 SQL 查询台恢复及后端配置/凭据进入客户端图。

修改代码后按[测试与验收](./测试与验收.md)选检查，并同步对应页面、HTTP、环境或搜索说明。纯文档执行链接/覆盖检查与 `git diff --check`；代码测试、API 配对、浏览器和生产证据分别记录。

组件/请求边界的原始论证及 R3 实施记录见[渐进重构研究](./模块边界与渐进重构计划.md)，模板和组件选型原稿见[设计与调研](./设计与调研.md)。
