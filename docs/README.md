## 文档事实源

Web 页面、组件、SSR/BFF、HTTP 消费和浏览器验证在本仓维护；API 最终授权、规则、Schema、事务、存储和运维见[私有 API 文档](https://github.com/gduf-community/competition-Q-A-website/tree/main/docs)。HTTP 参考直接给出消费合同，开发者不必先理解后端内部实现。

HTTP 参考维护路径/方法/包裹，搜索协议维护查询语义，环境说明维护传输配置，测试与验收维护验证入口。概览链接详细事实源，避免维护多份冲突规则。当前能力、批准计划、历史执行与尚未验收分别标注；页面、类型、构建、合并、看板与部署是不同事实。
