## BFF 与主要流程

唯一 [同源 BFF](<../src/app/api/[...path]/route.ts>)转发 `/api/**` 的 GET、HEAD、POST、PUT、PATCH、DELETE、OPTIONS；它只负责传输，[环境与 HTTP 边界](./开发环境与HTTP边界.md)规定来源、Cookie、IP 和故障处理。API 的完整接口与最终授权在其文档维护。

- 学生：发现比赛 → 查看时间/状态及官网或校内入口 → 登录后报名 → 个人中心跟踪、编辑或撤回。允许的操作由 API 当前状态与身份决定。
- 问答：比赛列表/详情进入问答 → 分页/详情 → 提问、回答、评论、采纳与治理。提交期间限制重复操作，成功刷新，失败保留输入。
- 成果：本人提交奖状并等待审核；经验文章和名人堂由管理员邀请，保留新建页面不表示允许自助创建。
- 管理员：按 API 当前能力进入 `/admin`，处理比赛/报名/通知、内容、分析与安全。菜单显隐不授予权限。
- 社团：当前仍从 `/me/clubs` 维护被授权内容并走平台审核。取消审核、统一后台入口和封面必传是 [API #70](https://github.com/gduf-community/competition-Q-A-website/issues/70)的已确认目标，不能写成现行能力。

`/admin/schedule` 是简版时间线；网站团队仍由代码内资料维护；SQL 台按结构化契约查询，安全动作以 API 已实现执行器为准。详细范围见[功能介绍](./功能介绍.md)。
