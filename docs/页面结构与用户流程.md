# 页面结构与用户流程

源码核对：2026-10-15，Web `0b0d594952897ea1d90c39b7afb5b7430571f078`。以下 70 项来自 `src/app/**/page.tsx`；路由组 `(auth)` / `(dashboard)` 不进入 URL。页面存在不代表已有操作权限，模式与接口分别见[环境说明](./开发环境与HTTP边界.md)及[HTTP 参考](./HTTP接口参考.md)。

## 页面入口与布局

[根 layout](../src/app/layout.tsx)提供全局外壳；[proxy](../src/proxy.ts)执行模式阻断与 API 访问检查，并覆写内部 callback 路径。public 阻断认证/本人/后台和 apply 页；错误页保留可达。

[个人 layout](../src/app/me/layout.tsx)要求登录；旧社团深链保留内部 callback，其余未登录个人入口回到 /me。[后台 layout](<../src/app/(dashboard)/admin/layout.tsx>)检查 API canAccessDashboard；社团 [slug 布局](<../src/app/(dashboard)/admin/clubs/[id]/layout.tsx>)再检查 getManagedClubs，未授权 slug 为不可见；联系方式 settings 另要求全局管理角色。其他内容/安全布局与 API 对象授权继续各自生效。

`/admin/clubs/[id]` 中 id 实际是固定社团 slug；它与内容的 contentId 不同。旧 `/me/clubs` 页面不再维护第二个内容工作台。

## 页面 → HTTP → 成功/失败流程

| 流程 | 读取与命令 | 更新与错误处理 |
| --- | --- | --- |
| 比赛发现 | SSR /api/competitions 元数据与 search=1 当前页；公开详情 /api/portal/competitions/[id] | URL 保存 q/mode/year/status/page/pageSize；非法参数可重置，服务失败可重试；默认 20/最多 50，不下载全表 |
| 登录与返回 | Auth.js credentials；SSR /api/me/session | 当前内部 callback 经校验后跳回；401 才是匿名，服务故障不伪装成未登录 |
| 报名 | trusted SSR /api/competitions/[id]；POST /api/applications、PUT /api/applications/[id] | 当前身份/模式/时间由 API 复核；提交锁、失败保留输入、成功回本人记录 |
| 本人记录 | /api/me/applications[/id]、withdraw、DELETE | accessRole/readOnly/editData 控制展示；写后刷新，时间线来自 logs；队员与本人权限不同 |
| 比赛问答 | SSR /api/questions 与详情；POST /api/questions/commands | 路径绑定 competitionId；按 canModerate/canAccept 展示，命令失败保留输入，成功刷新 |
| 成果与经验 | 奖状/人物公开 SSR；本人专用奖状上传；受邀经验/名人堂接口 | /me/experiences/new 实际重定向到列表；旧 achievements 深链再转向 experiences；不宣称可自助创建 |
| 社团内容 | /api/admin/clubs、contents；上传→创建/保存→publish | 固定授权 slug；封面上传完成才提交，保存复用 ID/revision，409 保留编辑，已发布保存直接更新；下线后显式重发 |
| 社团授权/治理 | /admin/users 独立 grant/revoke；governance 读取已发布内容并 offline | 赋权与普通用户权限更新分开；治理不授予编辑权；旧审核入口/绑定写接口已退役 |
| 报名审核/导出 | /api/admin/applications、单条/批量 review、单赛事 export | PII 读取与导出单独授权；文件字节专用下载，不能用 JSON 客户端解析 |
| 固定分析/安全 | /api/admin/analytics；security 列表/动作/回执及 situation SSE | 固定指标按响应口径；当前动作执行器仅 IP 放行/回滚，SSE 错误后关闭的限制需保留 |

完整方法、请求字段、返回包裹、二进制和 SSE 见[HTTP 参考](./HTTP接口参考.md)；查询排序/IME/URL 见[搜索协议](./搜索协议.md)。

## 别名、加载和未交付范围

- /login、/register 是 proxy 别名，不是额外 page.tsx，分别跳到 /sign-in、/sign-up。
- 根 [loading](../src/app/loading.tsx)、[error](../src/app/error.tsx)、[not-found](../src/app/not-found.tsx)负责共享状态；具体页面仍有局部空态、字段错误和重试，不能统一视为 not-found。
- /admin/schedule 是现有简版时间线；/team 为静态资料；SQL 页面已删除。荣誉年度 /awards/year/...、组队审批等计划按 Issue 交付，不添加虚构页面或接口。
- 当前社团迁移/切换、实际对象存储与真机输入验收见[测试与验收](./测试与验收.md)，路由与合成演练不代替生产结论。
