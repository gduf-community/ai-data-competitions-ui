## 配对联调与手工验收清单

按[环境说明](./开发环境与HTTP边界.md)启动独立 API 与 trusted Web，使用隔离合成数据库、身份与文件。逐项记录 Web/API SHA、模式、设备/引擎/视口、用例、结果和脱敏证据：

1. public：页面 SSR 数据可读；认证/本人/后台/报名进入被阻断；未允许的浏览器 JSON/方法 404；素材资格或版本失效后不可读。
2. 身份：登录、错误密码、会话刷新、退出、受保护深链 callback、注册/验证码/找回；401 与 API 不可用分别呈现。
3. 搜索：首次访问、空词/空结果、年份/状态/模式、末页、刷新/后退、重复/非法参数、IME Enter、防抖与清空焦点；API 失败可重试。
4. 报名：动态必填、个人/团队/指导老师、旧草稿恢复、重复提交限制、邮箱归属、本人/队员只读、修改/撤回/取消；详情 PII 和单赛事导出分别拒绝无权身份。
5. 问答：比赛作用域列表/详情、提问/回答/评论/采纳/治理、跨比赛拒绝、Markdown；写失败保留正文。
6. 社团：授权/撤权/到期、固定 slug、封面上传/替换失败/上传中提交、草稿保存/重开、直接发布/已发布编辑/下线后重发、409 保留输入、旧个人链接与 410 入口。
7. 成果/内容：本人奖状上传/审核回显、受邀经验/名人堂、自助创建拒绝；人物/素材公开资格与撤回。
8. 后台/安全：作用域筛选、固定分析口径、告警状态、真实执行/501、回执、SSE 到达/错误关闭/离开清理、文件下载与代理头。

实际 S3 的重启/重新部署持久性、生产数据库迁移、入口网络策略、移动 Safari/微信/手机输入法和资源峰值均需对应环境单独验收；开发机响应式模拟不代替真机。完整兼容矩阵见[浏览器兼容](./浏览器兼容策略与测试基线.md)。
