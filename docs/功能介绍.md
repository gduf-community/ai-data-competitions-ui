# 功能介绍

本文档只介绍公开 UI 仓库当前承载的前端展示功能。

## 1. 首页门户

首页门户是平台对外展示的主入口，负责说明“学院竞赛管理与问答平台”的定位，并把用户引导到比赛列表、个人中心、管理入口和荣誉展示等核心区域。

首页包含：

- 顶部导航：展示平台名称、主要栏目和用户入口。
- Hero 区域：展示平台主视觉、核心说明和重点比赛卡片。
- 重点赛事：展示近期可报名、即将开始或正在进行的比赛。
- 荣誉展示：展示获奖作品和竞赛达人。
- CTA 区域：引导用户查看比赛或进入个人报名记录。
- 页脚：展示平台入口、联系信息和备案占位信息。

## 2. 赛事展示

赛事展示功能用于把比赛信息以卡片和状态徽标的形式呈现出来，方便学生快速判断比赛是否值得关注。

当前支持展示：

- 比赛标题、类别、年份和承办部门。
- 比赛摘要和报名时间窗口。
- 报名方式，包括个人报名和团队报名。
- 比赛状态，包括报名中、即将开始、进行中、已结束、往期补录等。
- 比赛认定类型，包括校内名单、全国名单、双名单和名单外。
- 官网报名、校内信息收集和详情查看等行动入口。

## 3. 荣誉展示

荣誉展示用于沉淀学院竞赛成果，让首页不仅是报名入口，也能体现优秀作品和学生成长轨迹。

当前包含：

- 奖状作品墙：以图片网格展示获奖证书或成果海报。
- 获奖信息：展示比赛名称、获奖等级和获奖学生。
- 名人堂紧凑展示：以横向滚动卡片展示优秀参赛者。
- 个人标签：展示学生的代表性荣誉或竞赛身份。
- 简短简介：展示学生参赛方向、成果特点和经验标签。

## 4. 导航与布局

导航与布局功能用于统一学生门户页面的基础结构。

当前包含：

- 桌面端顶部胶囊导航。
- 移动端抽屉菜单。
- 登录态展示入口。
- 管理台入口展示规则。
- 滚动后导航压缩效果。
- 首页内容区域和页脚布局。

## 5. 通用 UI 组件

通用 UI 组件是后续页面扩展的基础，主要来自 shadcn/ui 风格体系，并按当前平台视觉做了整合。

当前包含：

- 基础操作：按钮、徽标、输入框、文本域、开关、复选框、单选框。
- 信息容器：卡片、表格、骨架屏、分隔线、面包屑。
- 弹层交互：弹窗、抽屉、下拉菜单、悬浮卡片、提示气泡、Popover。
- 表单展示：表单字段、标签、选择器、日历。
- 数据展示：图表容器、进度条、可调整面板。
- 导航结构：导航菜单、侧边栏、标签页、滚动区域。

## 6. 视觉与动效

视觉与动效功能用于增强门户展示感，但保持轻量，不绑定业务服务。

当前包含：

- Hero 渐变背景。
- 光晕装饰和点阵纹理。
- 鼠标跟随高光。
- 页面区块滚动渐入。
- 卡片错落出现。
- 名人堂跑马灯。
- 奖状墙视差滚动。

## 7. Mock 数据展示

Mock 数据用于让 UI 仓库脱离真实后端独立展示。

当前包含：

- 示例用户。
- 示例比赛。
- 示例报名记录。
- 示例通知。
- 示例荣誉墙数据。
- 示例名人堂数据。
- 首页聚合展示数据。

这些数据只用于页面预览和组件协作，不代表真实业务记录。
