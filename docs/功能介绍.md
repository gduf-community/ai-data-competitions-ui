# 功能介绍

本仓库承载平台唯一完整 Web：公开门户、认证页面、报名、个人工作台、问答、管理台和社团工作台。全部业务读取/写入通过 API；SSR 和 BFF 在本仓，数据库、授权、事务与存储管理在独立 API 仓库。

## 1. 首页门户

首页门户是平台对外展示的主入口，负责说明学院竞赛综合服务中心的定位，并把用户引导到比赛列表、通知公告、报名入口和荣誉展示等核心区域。

当前包含：

- 顶部胶囊导航：展示平台名称、主要栏目、通知入口和登录入口。
- Hero 区域：展示平台主视觉、核心说明、行动按钮和重点比赛卡片。
- 重点赛事：展示近期可报名、即将开始或正在进行的比赛。
- 荣誉展示：展示获奖作品、学生风采和学院竞赛成果。
- CTA 区域：引导用户查看比赛、阅读公告或进入个人报名记录。
- 页脚：展示平台入口、联系方式和备案占位信息。

## 2. 比赛列表

比赛列表功能用于把比赛信息以卡片、状态徽标和筛选器的形式呈现出来，方便学生快速判断比赛是否值得关注、是否仍可报名、是否属于学院重点推荐赛事。

当前支持展示：

- 比赛标题、类别、年份、承办部门和归属学院。
- 比赛摘要、报名时间窗口、比赛状态和报名方式。
- 个人报名、团队报名、校内信息收集、官网报名等入口展示。
- 报名中、即将开始、进行中、已结束、往期补录等状态。
- 校内名单、全国名单、双名单、名单外等认定类型。
- 年份切换、关键词搜索和状态筛选。

## 3. 荣誉展示

荣誉展示用于沉淀学院竞赛成果，让首页不仅是报名入口，也能体现优秀作品、获奖记录和学生成长轨迹。

当前包含：

- 奖状作品墙：以图片网格展示获奖证书或成果海报。
- 获奖信息：展示比赛名称、获奖等级、获奖学生和指导信息占位。
- 名人堂紧凑展示：以横向滚动卡片展示优秀参赛者。
- 个人标签：展示学生的代表性荣誉、竞赛方向或技术标签。
- 简短简介：展示学生参赛方向、成果特点和经验关键词。

## 4. 导航与布局

导航与布局功能用于统一学生门户页面的基础结构，保证后续新增页面在视觉和交互上保持一致。

当前包含：

- 桌面端顶部胶囊导航。
- 移动端抽屉菜单。
- 登录态展示入口。
- 管理台入口展示规则。
- 滚动后导航压缩效果。
- 首页内容区域、卡片网格和页脚布局。

## 5. 通用 UI 组件

通用 UI 组件是后续页面扩展的基础，主要来自 Radix UI / shadcn/ui 风格体系，并按当前平台视觉做了整合。

当前包含：

- 基础操作：按钮、徽标、输入框、文本域、开关、复选框、单选框。
- 信息容器：卡片、表格、骨架屏、分隔线、面包屑。
- 弹层交互：弹窗、抽屉、下拉菜单、悬浮卡片、提示气泡、Popover。
- 表单展示：表单字段、标签、选择器、日历。
- 数据展示：图表容器、进度条、可调整面板。
- 导航结构：导航菜单、侧边栏、标签页、滚动区域。

新增页面应优先复用现有通用组件。如果确实需要新增组件，建议在 PR 中说明复用场景、输入输出和视觉状态。

## 6. 视觉与动效

视觉与动效功能用于增强门户展示感，但保持轻量，不绑定业务服务。

当前包含：

- Hero 渐变背景。
- 光晕装饰和点阵纹理。
- 鼠标跟随高光。
- 页面区块滚动渐入。
- 卡片错落出现。
- 名人堂跑马灯。
- 奖状墙视差滚动。

动效应服务于信息层级，不应影响首屏可读性、移动端性能和基础可访问性。

## 7. 真实 API 与预览边界

页面读取当前 API 数据，不使用 Mock fallback。默认 public 预览仅访问公开读 DTO，不转发真实 Cookie、不接受写入，并阻断身份/本人/后台页面。受控 trusted 版本才接入完整业务流程；Web 不持有后端管理凭据。

认证、报名、本人资料/成果/经验、问答、管理及社团工作台已在本仓。纯合成夹具仅用于测试，禁止提交真实学生资料、Token 或生产配置。部署、入口 IP 与独立回滚证据另行核对，不能用页面存在代替验收。

## 8. 持续维护

- 比赛详情、报名、个人工作台与管理页面沿既有 HTTP 契约维护。
- 通知、问答、审核和社团流程由 API 当前权限与状态决定。
- 组件文档：为比赛卡片、状态徽标、筛选器和荣誉卡片补充 Props 说明。
- 无障碍优化：键盘导航、焦点状态、语义标签和对比度检查。
