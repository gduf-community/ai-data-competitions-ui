# competition-Q-A-website-ui

学院竞赛管理与问答平台的公开 UI 仓库，集中展示学生门户、竞赛信息、荣誉成果和通用界面组件。

## 功能概览

- 首页门户：展示平台定位、重点赛事入口、竞赛成果和行动引导。
- 赛事展示：提供比赛卡片、报名状态、赛事类别、时间窗口和报名入口展示。
- 荣誉展示：展示奖状作品墙、竞赛达人风采和成果沉淀。
- 导航布局：提供桌面端与移动端导航、用户入口和基础页面结构。
- 通用组件：沉淀按钮、卡片、弹窗、表单、表格、图表、侧边栏等 shadcn/ui 组件。
- 视觉动效：提供渐入、错落出现、跑马灯、光晕背景等轻量展示效果。
- Mock 数据：使用前端演示数据支撑页面独立预览和 UI 贡献。

## 当前页面

### 首页

首页由导航、Hero、重点赛事、荣誉展示、CTA 和页脚组成，用于展示学院竞赛平台的核心入口与视觉风格。

### 重点赛事

重点赛事区域以卡片方式呈现近期可参与或值得关注的比赛，突出比赛状态、报名方式、所属部门、年份和详情入口。

### 荣誉展示

荣誉展示区域包含奖状作品墙和名人堂紧凑展示，用于突出优秀参赛者、获奖记录和学院竞赛成果。

### 通用 UI

通用 UI 组件用于支撑后续页面扩展，保持按钮、弹窗、表格、表单、徽标和导航等基础体验一致。
